### 2.2 해석 시 주의
- **E7은 QB가 커버리지를 읽고 던질 곳을 고른 뒤의 결과**다. 그래서 "딥 패스 콜 대 Cover 0" 같은 콜 대 콜 상성으로 그대로 쓰면 안 된다. 엔진은 이를 두 단계로 나눈다: 커버리지가 실제 던진 깊이를 바꾸고(E5), 그 깊이에서 결과가 나온다(E7) (§5.3).
- **E9는 상황 구성의 영향**(점수 차, 남은 시간)이 섞여 있다. 크기는 보정 과정에서 재확인한다.
- 모든 표는 매 시즌 새 데이터로 다시 측정해 `data/baseline/`의 테이블과 함께 갱신한다.

## 4. 전술과 선수의 궁합

### 4.1 원리: 전술이 "어떤 능력치가 쓰이는지"를 정한다
별도의 "궁합 점수"를 곱하지 않는다. 대신 **매 플레이의 콜이 대결에 쓰이는 능력치와 가중치를 결정**한다. 그래서 궁합은 따로 만든 규칙이 아니라 결과로 나타난다.

- 존 커버리지 콜이면 CB의 **존 커버·IQ·볼 스킬**이 쓰이고, 맨 콜이면 **맨 커버·프레스·스피드**가 쓰인다. 맨 커버 17, 존 커버 9인 CB는 존 위주 팀에서 능력이 낭비된다.
- 아웃사이드 존 런이면 OL의 **민첩성·스피드·런 블록**이, 갭/파워 런이면 **근력·런 블록**이 쓰인다.
- 딥 패스 콜이면 QB의 **송구 파워·장거리 정확도**와 OL의 **긴 보호 시간**이 쓰이고, 퀵 패스면 **단거리 정확도·판단력**이 쓰인다.
- 블리츠 콜이면 LB·S의 **패스 러시**가 대결에 들어간다.

팀 전술은 이 콜들의 **비율**이므로, 로스터가 자주 쓰이는 능력치에서 강하면 궁합이 좋은 것이다.

### 4.2 콜별 능력치 가중치 (`config/scheme_weights.yaml`)
대결마다 콜에 따라 슬롯별 능력치 가중치를 둔다. 초기값 예시:

| 대결 · 콜 | 슬롯 | 가중치 |
|-----------|------|--------|
| 런 블록 · 아웃사이드 존 | OL | 런 블록 0.45, 민첩성 0.25, 스피드 0.15, 근력 0.15 |
| 런 블록 · 갭/파워 | OL | 런 블록 0.45, 근력 0.35, 민첩성 0.10, 스피드 0.10 |
| 러닝 · 아웃사이드 존 | RB | 비전 0.35, 가속 0.25, 스피드 0.20, 회피 0.20 |
| 러닝 · 갭/파워 | RB | 태클 돌파 0.35, 근력 0.25, 비전 0.25, 볼 안전성 0.15 |
| 커버리지 · 맨 | CB | 맨 커버 0.45, 프레스 0.20, 스피드 0.20, 민첩성 0.15 |
| 커버리지 · 존 | CB | 존 커버 0.45, 풋볼 IQ 0.25, 볼 스킬 0.20, 가속 0.10 |
| 패스 러시 · 3-4 프론트 | EDGE | 패스러시(피네스) 0.35, 스피드 0.25, 패스러시(파워) 0.25, 존 커버 0.15 |
| 패스 러시 · 4-3 프론트 | EDGE | 패스러시(파워) 0.35, 패스러시(피네스) 0.35, 근력 0.20, 가속 0.10 |
| 송구 · 딥 | QB | 장거리 정확도 0.45, 송구 파워 0.35, 포켓 감각 0.20 |
| 송구 · 퀵 | QB | 단거리 정확도 0.45, 판단력 0.35, 릴리즈(포켓 감각) 0.20 |

- 역할 평가(PRD F2-6)도 같은 가중치 파일을 쓴다. 역할 = "이 선수에게 유리한 콜 조합"이다.
- 가중치는 M3 보정 단계에서 실제 선수 성적을 가장 잘 설명하도록 다시 적합한다.

### 4.3 유닛 종합치
콜 `c`에서 유닛 `U`(예: OL 5명)의 종합치:

```
A_eff(i, a) = A(i, a) × m_fam(i, dim(c)) × m_cond(i) × m_inj(i)

C_U(c) = Σ_{i∈U} Σ_a w_{slot(i), a}(c) × A_eff(i, a)  /  Σ_{i∈U} Σ_a w_{slot(i), a}(c)

Δ(c) = (C_공격(c) − C_수비(c)) / σ_C          # σ_C = 리그 전체 종합치 표준편차 → Δ는 표준화 점수
```

- OL처럼 여러 명이 함께 막는 유닛은 **가장 약한 선수의 영향이 크도록** 가중 평균에 약점 보정을 더한다: `C_U = 0.7 × 평균 + 0.3 × 최저값`. 라인의 구멍 하나가 압박으로 이어지는 현실을 반영한다.
- 커버리지는 **맨이면 개별 매치업**(타깃 리시버 대 담당 CB), **존이면 유닛 평균**을 쓴다.

### 4.4 전술 숙련도 (Familiarity)
Football Manager의 전술 숙련도 개념. 전술을 자주 바꾸거나 새 체계를 도입하면 **실행력이 떨어진다**.

| 항목 | 규칙 |
|------|------|
| 숙련 영역 | 런 스킴(존/갭), 패스 컨셉(퀵/인터/딥/플레이액션/스크린), 프론트(4-3/3-4), 커버리지(맨 계열/존 계열), 블리츠 패키지, 특수팀 |
| 값 | 팀 전체 `F_team(d)`와 선수 개인 `F_i(d)`, 0–100 |
| 효과 | `m_fam = 0.92 + 0.08 × F/100` → 숙련도 0이면 해당 콜에서 능력치 8% 손실 |
| 부가 효과 | 숙련도가 낮으면 **정신적 실수** 증가: 폴스 스타트·오프사이드 확률, 커버리지 붕괴(BLOWN) 확률 |
| 증가 | 주간 훈련(§7), 해당 영역을 경기에서 사용 (+2/경기, 사용 비중 20% 이상일 때) |
| 감소 | 사용 비중 5% 미만인 영역은 주당 −1 |
| 신규 선수 | 이전 팀 전술과의 유사도로 시작값 결정. 실제 선수는 **이전 팀의 실측 성향**(맨 비율, 블리츠율, 런 스킴)으로 계산. 정보가 없으면 50 |
| 게임 시작 | 모든 팀은 2025 시즌 실측 성향과 비슷한 전술이면 80, 크게 다르면 차이에 비례해 낮게 시작 |

### 4.5 사용자에게 보여주는 궁합 지표
- **선수 궁합**: 현재 팀 콜 비율로 계산한 그 선수의 기여도 ÷ 그 선수에게 가장 유리한 콜 비율로 계산한 기여도. 0.85 미만이면 "전술과 맞지 않음" 경고.
- **팀 궁합**: 포지션 그룹별 선수 궁합의 스냅 가중 평균.
- **전술 변경 미리보기**: 슬라이더를 바꾸면 궁합과 숙련도 변화, 예상 EPA/플레이 변화를 즉시 계산해 표시 (PRD F4-8d).

## 5. 플레이 결과 계산

### 5.1 공통 방식
- **분위수 이동**: 기본 분포에서 균등 난수 `u`를 뽑고, `u' = Φ(Φ⁻¹(u) + s)`로 옮긴 뒤 분포의 `u'` 분위 값을 결과로 쓴다. `s`는 아래 기여분의 합이다. 분포의 모양(긴 꼬리, 빅 플레이 빈도)은 실측 그대로 유지된다.
- **로짓 이동**: 확률형 결과는 `p' = σ(logit(p0) + s)`.
- 기여분 `s`의 구성 (모두 기록, §8):

```
s = β_k × Δ(c)              # 능력치·궁합·숙련도 차이 (§4)
  + s_anticipation          # 읽힘 효과 (§6.5)
  + s_drill                 # 이번 주 상황 훈련 보너스 (§7)
  + ε × (1 − 일관성/25)      # 일관성 낮은 선수일수록 흔들림
```

### 5.2 압박
```
p_press = σ( logit(p0[수비 콜, 러셔 수, 다운 구분])
           + β_press × Δ_rush(c)                    # 러셔 대 블로커
           + δ_obvious × max(0, b_pass − 0.8) )     # 뻔한 패스 상황에서만 (E9b)
```
- `p0`: 블리츠 없음 25.6%, 블리츠 39.4%, Cover 0 44.8%, 3rd & long 36.7% (E4, E6, E9b).
- 압박이 발생하면 색·스크램블·서두른 송구로 분기한다. 비율은 실측 테이블을 따른다.

### 5.3 패스: 던질 곳 → 결과
1. **의도한 깊이**: 공격 콜(퀵/인터/딥/플레이액션/스크린)이 의도 분포를 정한다.
2. **실제 던진 깊이**: 수비 커버리지가 의도를 바꾼다.
   ```
   P(깊이 | 콜, 커버리지, 압박) ∝ 의도[콜][깊이] × R[커버리지][깊이] × P_press[압박][깊이]
   ```
   - `R`은 E5에서 구한 "커버리지별 깊이 비율 ÷ 전체 평균 비율". 예: Cover 2는 퀵 패스 ×1.2, 딥 ×0.8.
   - 예: 딥 콜을 불렀는데 상대가 Cover 2면 체크다운이 늘어난다. 딥 위주 팀이 Cover 2 위주 팀을 만나면 불리한 이유가 여기서 나온다.
3. **결과**: 기본 분포 `T_pass[깊이, 커버리지, 압박, 상황]`에서 완성 여부, 에어 야드, YAC, INT를 뽑는다. 완성·INT는 로짓 이동, 야드는 분위수 이동.
   - 완성: Δ = (QB 깊이별 정확도·판단력 + 리시버 루트·릴리즈·캐칭) 대 (커버리지 + 볼 스킬)
   - YAC: Δ = (리시버 회피·태클 돌파·스피드) 대 (수비 태클·추격)
   - INT: Δ = (QB 판단력) 대 (수비 볼 스킬), 압박 시 기본 확률 상승

### 5.4 런
```
결과 ~ T_run[런 콜, 박스 인원, 상황]   # E1
Δ = (OL 런 블록 + RB 콜별 능력 + FB·TE 블록) 대 (DL 블록 떨치기·런 스톱 + LB 태클)
```
- 박스 인원은 수비 콜(로디드 박스, 라이트 박스)과 공격 퍼스넬이 정한다 (E10).
- 플레이액션은 박스 7명 이하일 때만 이점을 준다 (E11).

### 5.5 계수 적합
- `β_k`(대결별 능력치 민감도)는 M3에서 적합한다. 목표: 2023–2024 데이터로 만든 능력치로 2025 시즌을 돌렸을 때 **팀별 공격·수비 EPA/플레이 분산과 순위가 실제와 가장 가깝게**.
- 초기값은 팀 간 표준편차 0.10을 재현하는 수준에서 시작한다.
- **M3 결과**: 계수별 초기값은 유지하고 전체 배율 `beta_scale` = 1.25로 적합 (팀 득실차 분산비 0.97, 득실차 순위 ρ 0.46). 상세는 §14.

## 6. 뻔한 전술의 대가

### 6.1 원리: 두 가지 경로
별도의 "예측 가능성 벌점"은 없다. 대가는 두 경로로 자연스럽게 생긴다.

| 경로 | 내용 | 근거 |
|------|------|------|
| **① 콜 대응** | 상대가 성향을 학습해서 **맞는 콜을 더 자주 고른다**. 런이 뻔하면 로디드 박스, 패스가 뻔하면 블리츠나 딥 존 | E1, E3, E5, E7 |
| **② 읽힘 효과** | 같은 콜이라도 상대가 예상한 플레이는 **더 잘 막힌다**. 스냅 전 단서, 수비수의 첫 반응, 커버리지 깊이 조정이 콜에 다 담기지 않기 때문 | E9, E9b |

경로 ①만 있으면 실측 효율표상 **모든 수비 콜에 대해 패스가 런보다 나아서 "항상 패스"가 정답**이 된다 (§6.7 모형 1행). 경로 ②가 있어야 극단적 패스 성향도 대가를 치른다.

### 6.2 상황 버킷과 퍼스넬
믿음은 상황별로 따로 관리한다.

| 축 | 구분 |
|----|------|
| 다운·거리 | 1st & 10, 2nd & 짧음(1–3), 2nd & 중간(4–7), 2nd & 김(8+), 3rd & 짧음, 3rd & 중간, 3rd & 김, 4th |
| 필드 | 자진영 깊숙이(−10 안쪽), 중간, 상대 진영, 레드존, 골라인 |
| 점수·시간 | 접전, 크게 앞섬(후반 9점+), 크게 뒤짐(후반 9점+), 2분 드릴 |
| 공격 퍼스넬 | 10, 11, 12, 13, 21, 22, 기타 |

- 수비는 **공격 퍼스넬을 보고 나서** 콜을 고른다. 그래서 "12 퍼스넬이면 거의 런" 같은 팀은 퍼스넬만으로 읽힌다 (E10).
- 표본을 나누면 학습이 느려지므로 **계층 공유**를 쓴다: 관측은 세부 버킷에 1, 퍼스넬을 뺀 상위 버킷에 0.5, 다운만 남긴 버킷에 0.25씩 더한다. 믿음은 세부 → 상위 순으로 표본 수에 따라 섞는다.

### 6.3 믿음 모델 (디리클레)
```
α_s(a) = κ × p_prior(a | s)                       # 경기 시작 시
p_prior = w_scout × p_scout(a | s) + (1 − w_scout) × p_league(a | s)
b_s(a) = α_s(a) / Σ α_s                           # 현재 믿음
관측 후: α_s(a_실제) += 1   (계층 공유 포함)
```
- `a`는 공격 플레이 패밀리(수비 쪽 믿음) 또는 수비 콜 패밀리(공격 쪽 믿음).
- `p_league`: 재학습한 xpass 모델과 리그 평균 패밀리 비율.
- `p_scout`: 상대의 **이번 시즌 경기 기록**. 1주차는 실제 2025 시즌 팀 성향. 전술을 크게 바꾼 팀(코치 교체 등)은 상대가 모르므로 초반에 유리하다.
- `κ`(사전 믿음의 강도, 가상 플레이 수): 기본 20. 코디네이터 능력과 **주간 훈련의 "상대 분석" 초점**으로 커진다 (§7).
- `w_scout`: 스카우팅 기록 경기 수에 비례 (0경기 0.3 → 4경기 이상 0.8).

### 6.4 콜 선택
수비 기준. 공격도 대칭이다.
```
V(c) = Σ_a b_s(a) × Ê[공격 EPA | a, c, 양 팀 유닛 종합치]      # 이번 경기 로스터 기준으로 경기 전 미리 계산
BR(c) = softmax(−V(c) / τ)                                      # 확률적 최선 대응
π(c) = (1 − λ) × B_D(c | s) + λ × BR(c)                         # 팀 정체성과 대응의 혼합
```
| 파라미터 | 의미 | 기본값 |
|----------|------|--------|
| `B_D` | 사용자·AI 전술 설정이 정한 콜 비율 (팀의 정체성) | 전술 화면 |
| `λ` | **상대 대응 강도**. 0이면 전술 그대로, 클수록 상대에 맞춤 | 사용자 0.35 (0–0.7 슬라이더), AI는 코디네이터 능력 0.2–0.5 |
| `τ` | 대응의 정밀도 (EPA 단위). 작을수록 최선 콜에 집중 | 0.02, 코디네이터 능력으로 0.01–0.04 |

- `λ`에 상한(0.7)을 두는 이유: 두 팀이 서로 완전히 대응하면 콜이 한쪽으로 쏠렸다가 뒤집히는 진동이 생긴다. 정체성 비중이 이를 막는다.
- `Ê`는 경기 시작 시 "공격 패밀리 × 수비 콜" 행렬로 미리 계산한다 (버킷 종류별, 약 9 × 12). 플레이마다 행렬 곱 한 번이라 성능 부담이 없다.
- **공격 쪽**: 공격은 수비의 블리츠율·박스·커버리지 성향을 학습해서, 사용자가 허용한 플레이 패밀리 범위 안에서 대응한다. 예: 상대가 블리츠를 자주 하면 스크린과 퀵 패스가 늘어난다 (E3).
- **사용자 팀도 같은 규칙으로 대응한다**. 경기 중에 사용자가 조작하지 않을 뿐, 경기 전에 정한 `λ`와 게임플랜 범위 안에서 AI 코디네이터가 대응한다. PRD의 "사전 전술만" 원칙(D2)과 맞는다.

### 6.5 읽힘 효과 (경로 ②)
```
s_anticipation(a) = −γ_k × max(0, b_s(kind(a)) − b_neutral(kind(a) | s))
```
- `kind(a)`는 런 또는 패스. `b_neutral`은 그 상황의 리그 평균 기대 패스 확률(xpass).
- 초기값: **γ_pass = 0.30, γ_run = 0.03** (EPA 환산 기준). E9에서 패스는 기대 확률이 높을수록 뚜렷하게 나빠지고, 런은 경향이 없었기 때문이다.
- 실제 적용 시에는 EPA가 아니라 분위수 이동 단위로 바꿔 쓴다. 변환 계수는 보정 과정에서 구한다.
- 뻔한 패스 상황에서는 읽힘이 **압박 증가**로도 나타난다 (§5.2의 `δ_obvious`, E9b).
- 보정 목표: 리그 전체 시뮬레이션에서 "기대 패스 확률 구간별 드롭백 EPA"가 E9와 같은 기울기(약 −0.05)를 보일 것. 경로 ①과 ②의 합으로 맞춘다. 실측값에는 두 경로가 모두 들어 있으므로 따로 맞추면 이중 계산이 된다.

### 6.6 성향 숨기기와 성향 깨기
사용자가 예측 가능성을 관리하는 수단이다 (PRD F4-9).

| 설정 | 효과 | 비용 |
|------|------|------|
| **퍼스넬 섞기** | 같은 퍼스넬에서 런·패스를 고르게 → 퍼스넬로 읽히지 않음. 헤비 퍼스넬 패스는 실측상 효율이 높다 (E10) | 역할에 안 맞는 선수가 필드에 서는 횟수 증가 → 궁합 손실 |
| **성향 깨기** (끔/보통/적극) | 공격 AI가 자기 노출도(상대 믿음이 중립에서 벗어난 정도)를 감시하다가 기준을 넘으면 덜 쓴 패밀리 비중을 올림 | 선호하지 않는 플레이를 부르는 비용 |
| **상대 대응 강도 `λ`** | 상대 성향에 더 맞춰 대응 | 우리 정체성(숙련도가 높은 콜)에서 벗어남 |

### 6.7 단순 모형 검증
`tools/research/predictability_toy.py`: 공격은 런/패스, 수비는 콜 4개, 효율은 실측값을 쓴 모형이다. 60플레이 경기를 조건별 1,500–3,000회 돌렸다.

| 설정 | 런 0% | 런 15% | 런 30% | 런 40% | 런 50% | 런 65% | 런 80% |
|------|------|------|------|------|------|------|------|
| 읽힘 없음, 대응 없음 | **+0.078** | +0.054 | +0.030 | +0.014 | −0.002 | −0.028 | −0.054 |
| 읽힘 0.23, 대응 0.35 | +0.016 | **+0.018** | +0.014 | +0.007 | −0.006 | −0.033 | −0.062 |
| 읽힘 0.35, 대응 0.35 | −0.013 | +0.002 | **+0.007** | +0.004 | −0.007 | −0.033 | −0.062 |

| 경기 내 변화 (읽힘 0.23, 대응 0.35) | 전반 | 후반 |
|--------------------------------------|------|------|
| 런 0% (패스만) | +0.033 | **−0.001** |
| 런 40% | +0.007 | +0.005 |
| 런 80% | −0.060 | −0.065 |

**결론**
1. 읽힘 효과가 없으면 "항상 패스"가 정답이다. 경로 ②는 필수다.
2. 읽힘 0.23–0.35에서 최적 런 비율이 **15–30%** 로 들어온다. 실제 엔진에는 커버리지·압박·퍼스넬 차원이 더해지므로, G3 목표(25–45%)는 전체 엔진에서 다시 맞춘다. 초기값은 0.30으로 둔다.
3. 패스만 하는 팀은 **상대가 학습한 후반에 효율이 사라진다**. 중계와 리포트에서 "상대가 우리 패턴을 읽었다"는 이야기가 자연스럽게 생긴다.
4. 런 위주 팀의 손해는 대부분 런 자체의 낮은 효율에서 온다. 수비 대응이 추가로 빼앗는 몫은 작다 (0.005–0.01). 실측상 런 결과가 수비 콜에 덜 민감하기 때문이다.

## 7. 주간 준비와 엔진의 연결

PRD F11(주간 훈련)이 엔진에 주는 효과. 구단주 목표(F12)와 스카우팅 정보 공개(F13)는 엔진 계산에 관여하지 않는다. 단, 구단주 기대치는 엔진으로 시즌을 미리 시뮬레이션해서 정한다.

### 7.1 훈련 초점
| 초점 | 엔진 효과 (강도 "보통" 기준) |
|------|------------------------------|
| 전술 숙련 (영역 선택) | 선택 영역 숙련도 +5, 다른 영역 +1.5 |
| 상대 분석 | 다음 경기 사전 믿음 강도 `κ` ×1.5, 스카우팅 가중 `w_scout` +0.1. 우리 공격·수비 코디네이터 모두 적용 |
| 레드존 / 3rd down / 2분 드릴 | 해당 상황에서 이번 주 `s_drill` = +0.06 (분위수 이동 표준화 단위) |
| 특수팀 | 킥·리턴 대결 `s_drill` +0.06, 특수팀 숙련도 +5 |
| 회복 | 주간 컨디션 회복 +10, 효과 보너스 없음 |

### 7.2 훈련 강도
| 강도 | 효과 배율 | 컨디션 | 훈련 중 부상 위험 |
|------|-----------|--------|-------------------|
| 가벼움 | ×0.4 | +10 회복 | ×0.5 |
| 보통 | ×1.0 | 기준 | ×1.0 |
| 강함 | ×1.6 | −10 | ×1.5 |

- 훈련 중 부상 기본 확률: 선수당 주 0.3% (초기 추정치, 부상 리포트의 "경기 없는 주 신규 부상"으로 보정).
- 부상 선수의 훈련 참여 단계(DNP/Limited/Full, PRD F10-3)는 훈련 효과도 줄인다: Limited ×0.5, DNP ×0.

## 8. 기록과 설명 가능성

매 플레이 로그 (PRD `Play` 테이블 확장):

| 필드 | 내용 |
|------|------|
| `off_call`, `def_call`, `personnel`, `box`, `rushers` | 양 팀 콜과 배치 |
| `def_belief_pass`, `off_belief_blitz` | 콜 직전 양쪽 믿음 |
| `def_call_prob_identity`, `def_call_prob_br` | 이 콜이 정체성에서 나왔는지, 대응에서 나왔는지의 확률 |
| `s_rating`, `s_fit`, `s_fam`, `s_anticip`, `s_drill` | 결과 이동 기여분 분해 |
| `pressure`, `throw_depth`, `ep_before`, `ep_after` | 결과 |

`s_fit`은 "현재 콜 가중치로 계산한 Δ"와 "해당 선수들에게 가장 유리한 콜 가중치로 계산한 Δ"의 차이로 구한다. 궁합 때문에 잃은 몫을 따로 보여주기 위해서다.

리포트는 이 기여분을 합산해 보여준다. 예: "이번 경기 패스 공격은 능력치 우위로 +0.04, 읽힘으로 −0.03, 존 커버 CB 궁합 손실로 −0.01".

```python
class Belief:
    def __init__(self, prior: dict[Bucket, np.ndarray], kappa: float) -> None: ...
    def probs(self, bucket: Bucket) -> np.ndarray: ...          # 계층 혼합 믿음
    def observe(self, bucket: Bucket, family: int) -> None: ...  # 계층 공유 갱신
    def exposure(self) -> float: ...                             # 노출도 (KL)

class Coordinator:
    def __init__(self, identity: CallTable, lam: float, tau: float,
                 belief: Belief, payoff: PayoffMatrix) -> None: ...
    def choose(self, state: GameState, bucket: Bucket, rng: Generator) -> CallChoice: ...
    # CallChoice는 콜과 함께 정체성/대응 확률을 담아 로그로 넘긴다

def unit_composite(players: list[OnField], unit: Unit, call: Call,
                   weights: SchemeWeights) -> float: ...
```

```python

off_coord.belief.observe(bucket, def_call.family)
```

### 2025 재현 테스트 (`tools/reproduce_season.py --season 2025`)

**방법**: 2022–2024 기록만으로 만든 능력치 + 2025 개막(1주차) 로스터·뎁스차트로 2025 정규시즌 272경기를 반복 시뮬레이션해 실제 결과와 비교한다. 시즌 중 부상·트레이드·감독 교체는 반영하지 않으므로 **개막 시점 예측력**을 재는 시험이다. 중심값은 그 시즌 능력치 분포로 다시 잰다.

|--------|---------------|-------------|-------------|------------------------------------|-------------------------|
| 1.0 | 0.43 | 0.36 | 0.32 | 0.82 | 21.7 |
| **1.25** | **0.45** | **0.45** | **0.41** | **1.01** | **22.0** |
| 1.5 | 0.51 | 0.52 | 0.26 | 1.20 | 22.0 |
| 1.75 | 0.40 | 0.39 | 0.31 | 1.35 | 22.8 |
| 2.0 | 0.43 | 0.40 | 0.12 | 1.51 | 23.0 |
| 3.0 | 0.45 | 0.38 | 0.22 | 2.15 | 25.3 |

- 순위 상관은 1.0–1.5 구간에서 반복 잡음(±0.05) 안에서 비슷하고, 분산비는 β에 따라 뚜렷하게 움직인다. 그래서 §5.5 목표대로 **분산비 ≈ 1인 1.25**를 채택했다.
- β를 키우면 수비 쪽 상관이 먼저 무너진다 (수비 능력치가 공격보다 잡음이 큼 — RAPM 커버리지 계수의 한계).

- 실측 능력치 리그의 리그 평균 (2026, 800경기): 득점 21.5, 완성률 65.2%, Y/A 6.97, YPC 4.42, 색 6.6%, INT 2.53%, FG 84.7% — §8.4 목표 범위.

### M3 이후 남은 과제
- 커버리지·런 수비 RAPM은 잡음이 크다. M4에서 콜별 능력치 가중치를 적합할 때 수비 쪽 가중치를 함께 다시 본다.
- 일관성·결단력·큰경기 강도는 아직 임시 생성값이다 (기록으로 추정할 신호가 약함). 엔진에서 쓰기 시작하는 M4·M5에서 다시 정한다.
- 패스 러시 피네스/파워 구분은 기록으로 나눌 수 없어 체격(스피드−근력)으로 기울기만 준다.

# Gridiron Manager — MVP 릴리즈 노트 (v1.0, 2026-10-31)

Football Manager 스타일 NFL 매니지먼트 시뮬레이션. 2026 실제 로스터·일정, 실측 기반 경기 엔진, 웹 UI.

## 실행
```bash
pip install -e ".[dev,web]"
gridiron serve            # http://127.0.0.1:8000 → 새 게임에서 팀 선택
```

## 할 수 있는 것
- **새 게임**: 32팀 중 하나의 단장 겸 감독. 2026 실제 로스터·뎁스차트·일정, 직전 3시즌 기록으로 산출한 1–20 능력치.
- **매주**: 전술(공격·수비 철학, 상황별 성향, 프리셋·내 프리셋, 궁합·노출도 실시간 미리보기, 엔진 비교 시뮬), 게임플랜(상대 스카우팅 리포트),
  주간 훈련(숙련도·컨디션), 뎁스차트(드래그), 로스터(53인·연습 스쿼드·IR·FA 영입·임시 승격), 부상 관리(출전 결정·IR), 스카우트 배정.
- **경기**: 매치 센터 중계(전체·하이라이트·즉시, 승률 그래프), 박스스코어·드라이브 차트·전술 효과 리포트(플레이 패밀리·커버리지별 EPA, 쿼터별 효율)·선수 평점.
- **시즌**: 공식 타이브레이커·플레이오프·슈퍼볼, 리그 통계·리더보드, 시즌 어워드·올프로, 구단주 목표·신뢰도·평가(해고는 설정에서 끌 수 있음).
- 모든 기능은 CLI(`gridiron --help`)로도 쓸 수 있다.

## 엔진 정확도 (실측 대비)
- 리그 평균: 득점 22.4 (실측 22.5), 완성률 65.4% (64.4%), Y/A 7.17 (7.0), 색 6.5% (6.9%), INT 2.26% (2.2%).
- 경기 변동성: 같은 매치업 득실차 잔차 SD 13.4 (실측 ≈13.4).
- 2025 시즌 재현(2022–2024 기록만으로): 팀 득실차 순위 상관 0.45, 분산비 0.93.
- 공식 타이브레이커: 2021–2025 실제 와일드카드 대진 5시즌 모두 재현.
- 부상: 팀·경기당 2.2건, 결장 기간 분포 실측과 일치.
- 전술 검증 T1–T9 중 8개 통과 (ENGINE_DESIGN §16.4).

## 알려진 한계
- 패스 TD가 실측보다 ≈15% 많아 시즌 리더 기록(패싱 TD 45+, 리시빙 2,000야드급)이 높게 나올 수 있다.
- 런 비율에 따른 공격 효율 곡선이 평평하다 (T5).
- 한 시즌만 진행된다 (오프시즌·다년 커리어는 Post-MVP).
- 난이도 설정, 로테이션·퍼스넬 패키지 배치, 슬롯 역할 지정은 아직 없다.
